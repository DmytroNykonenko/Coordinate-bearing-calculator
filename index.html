Калькулятор координат та азимутів

Excel → азимути, відстані, площа → готовий Excel

Правило: 1-ша колонка — назва точки, 2-га — Easting/X, 3-тя — Northing/Y. Назви колонок можуть бути будь-які.
Завантажте Excel-файл для початку.

Попередній перегляд

Розрахунок виконується у вашому браузері. Файл координат не завантажується на сервер.
